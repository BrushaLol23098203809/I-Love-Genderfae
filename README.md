## I heart GenderFae
Welcome to the iLoveGenderfae Pride repository! This project is a clone of the iLoveGenderfae website, built using Tailwind CSS. It is a fully responsive website, meaning it adapts seamlessly to various screen sizes and devices.

I heart genderfae is an open-source voice labeling application with the following objectives:

Delivering a modern and seamless UI/UX.
Offering a customizable labeling process suitable for various voice generation software.
Ensuring high performance and support across multiple platforms.
For assistance, feedback, reporting issues, and more.
## Features
Responsive Design: The website is optimized to work flawlessly across different devices, including desktops, tablets, and mobile phones.
Tailwind CSS: Built using Tailwind CSS utility-first framework for rapid development and easy customization.
